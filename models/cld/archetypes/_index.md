# CLD Archetypes — Index

The twelve canonical archetypes from Senge's *Fifth Discipline* and its extensions. Each archetype is a recurring **loop pattern** that shows up across domains. Recognizing the pattern shortcuts the diagnosis.

This file is the lookup table. Each archetype has its own file with full structure (signature, slots, loops in DSL, classic example, recognition triggers).

| ID | Name | One-liner signature | Trigger keywords |
|---|---|---|---|
| `balancing-process-with-delay` | Balancing Process with Delay | A correction overshoots because the feedback arrives too late | "we keep over-correcting", "swings", "by the time we see it, it's too late" |
| `limits-to-growth` | Limits to Growth | Growth slows as a hidden constraint kicks in | "it used to work, now it's plateauing", "we hit a ceiling", "diminishing returns" |
| `shifting-the-burden` | Shifting the Burden | A symptomatic fix relieves pressure to apply the fundamental solution | "quick fix", "we never get to the root cause", "dependency on the workaround" |
| `shifting-the-burden-to-the-intervenor` | Shifting the Burden to the Intervenor | An external helper takes over what the system should do for itself | "they handle it for us now", "we forgot how to do this ourselves", "vendor lock-in" |
| `eroding-goals` | Eroding Goals | Goals are quietly lowered when reality fails to meet them | "we revised the target", "good enough", "the bar keeps dropping" |
| `escalation` | Escalation | Two parties' defensive responses amplify each other | "arms race", "tit for tat", "they raised, so we had to raise" |
| `success-to-the-successful` | Success to the Successful | Resources flow to the already-winning option, starving alternatives | "the rich get richer", "Matthew effect", "winner takes all" |
| `tragedy-of-the-commons` | Tragedy of the Commons | Individually rational use degrades a shared resource | "everyone is doing it", "shared pool is exhausted", "no one's responsible" |
| `fixes-that-fail` | Fixes that Fail | A fix works short-term but creates a worse version of the problem later | "the fix made it worse", "déjà vu", "boomerang", "every time we patch it, it comes back bigger" |
| `growth-and-underinvestment` | Growth and Underinvestment | Growth stalls because investment in capacity always trails the need | "we can't keep up", "demand outran capacity", "we should have invested earlier" |
| `accidental-adversaries` | Accidental Adversaries | Two parties who would benefit from cooperation drift into conflict | "we used to work together", "now they're blocking us", "neither side wanted this" |
| `rule-beating` | Rule Beating | People comply with the letter of the rule while defeating its purpose | "they game the metric", "letter not spirit", "the KPI went up but nothing improved" |

## How to use this index

- **For learning**: read the one-liners, then click through to the full file when one resonates with a situation
- **For pattern matching**: grep the trigger keywords against a user's situation description; rank candidate archetypes by hit count; offer the top 1-2 for confirmation
- **For instance creation**: once an archetype is identified, the corresponding file lists its slots — the Builder fills these from the user's concrete situation
